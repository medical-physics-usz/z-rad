# Contributing to Z-Rad

Report bugs or request features through [GitHub Issues](https://github.com/medical-physics-usz/z-rad/issues). To contribute code or documentation, follow the [contributing guide](https://medical-physics-usz.github.io/z-rad/developer/contributing.html) in the development docs.

For a pull request:

1. [Set up a development environment](https://medical-physics-usz.github.io/z-rad/developer/development_environment.html) and keep the change focused.
2. Add or update tests for changed behavior. Run the unit suite and any relevant integration tests, then check formatting and lint. The [testing](https://medical-physics-usz.github.io/z-rad/developer/testing.html) and [code quality](https://medical-physics-usz.github.io/z-rad/developer/code_quality.html) guides give the commands.
3. Update documentation for changed behavior or APIs. If you change the docs, [build them locally](https://medical-physics-usz.github.io/z-rad/developer/building_docs.html); the documentation workflow does not run on pull requests.
4. Explain the problem, the change, how you checked it, and any limitations in the pull request. Review its [CI results](https://medical-physics-usz.github.io/z-rad/developer/ci.html) and address failures before requesting review.

The development guide has more detail on IBSI validation, benchmarks, and where to make documentation changes.
