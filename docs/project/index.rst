About Z-Rad
===========

Z-Rad is a radiomics toolkit developed in the Department of Radiation Oncology
at University Hospital Zurich. It provides both a graphical interface and a
Python API for preprocessing DICOM and NIfTI images, applying filters, inspecting
images and masks, and extracting radiomic features.

Automated tests compare Z-Rad results with published references from the Image
Biomarker Standardisation Initiative (IBSI). See :doc:`../ibsi/index` for tested
configurations and limitations.
